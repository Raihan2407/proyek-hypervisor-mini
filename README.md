## 📖 Tentang Project

Project ini bertujuan untuk:
- Memahami konsep virtualisasi level Operating System
- Mengimplementasikan hypervisor menggunakan QEMU/KVM
- Mengelola virtual machine dengan libvirt
- Melakukan benchmark dan analisis performa VM

---

## 🛠️ Technology Stack

- **Hypervisor:** QEMU/KVM
- **Management Tool:** libvirt, virt-manager  
- **Host OS:** Ubuntu 22.04 LTS
- **Guest OS:** Ubuntu Server 22.04 LTS
- **Benchmark Tools:** sysbench, stress-ng
